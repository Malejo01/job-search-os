# Seguridad

Si encontraste una vulnerabilidad, avisanos en privado desde la pestaña **Security › Report a vulnerability** de este repositorio. No abras un issue público.

Contanos qué encontraste, cómo reproducirlo y qué impacto tiene. No hace falta que pruebes contra cuentas ajenas ni que accedas a datos de otras personas para demostrarlo.

Respondemos el reporte y te avisamos cuando quede resuelto.
